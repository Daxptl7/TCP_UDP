Client Socket Lifecycle

  1. s = socket(AF_INET, SOCK_STREAM) - Allocate TCP endpoint
  2. s.connect((host, port)) - Sends SYN, receives SYN-ACK, sends ACK
  3. s.sendall(data) / s.recv(1024) - Full-duplex data transfer
  4. s.close() - Sends FIN, triggers 4-way termination

Server Socket Lifecycle

  1. s = socket(AF_INET, SOCK_STREAM) - Allocate TCP endpoint
  2. s.bind(('', port)) - Bind to local address and port
  3. s.listen(backlog) - Transition into passive LISTEN mode
  4. c, addr = s.accept() - Blocks until 3-way handshake completes
  5. c.sendall(data) / c.recv(1024) - Communicate with accepted client
  6. c.close() - Release active connection socket

Procedure 1: Client Program that Connects to Google.com

DNS Resolution + HTTP Request

Resolves domain www.google.com to an IP address via DNS, initiates a TCP handshake on port 80, sends an HTTP request, and parses the response headers.

Interactive Live Simulator

$ python3 01_google_client/client.py
Ready to execute. Click above.

Python 3 Code Implementation

import socket

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
host = socket.gethostbyname('www.google.com')
port = 80

s.connect((host, port))
print("socket connected to google http server")

# Send HTTP HEAD request
req = "HEAD / HTTP/1.1\r\nHost: www.google.com\r\nConnection: close\r\n\r\n"
s.sendall(req.encode('utf-8'))
response = s.recv(1024)
print(response.decode('utf-8'))
s.close()

Procedure 2: Server Program with Telnet / Netcat Interaction

Passive Listen & Accept

Server creates a socket, binds to port 12345, listens with a backlog queue of 5, accepts an incoming client, transmits Thank you for connecting\n, and closes the connection.

Interactive Simulator

$ Server active on port 12345
Server listening for incoming connections...

Python 3 Code Implementation

import socket

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
port = 12345
s.bind(('', port))
s.listen(5)

while True:
    c, addr = s.accept()
    print('Got connection from', addr)
    c.send(b'Thank you for connecting\n')
    c.close()
